# Study App

Early personal study-tracking prototype built during the first AI-coding phase
in April 2026.

## Position

This repo is best treated as a Claude-era prototype, not as a current
production system or a component of Global Life Operations. It is useful in a
portfolio timeline because it shows the starting point: small tools for real
personal needs before the later shift toward YNU LMS Agent, CrowdWorks Agent,
and staged-autonomy operations.

## What It Contains

- A Tkinter-style local study tracker in `study_app.py`.
- A Flask/SQLite web version in `app.py` and `templates/`.
- Render deployment config in `render.yaml`.

## Public Presentation

Show this only as an early milestone. Current operational academic automation
